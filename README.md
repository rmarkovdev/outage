# Світло — графік відключень

Застосунок для iPhone (PWA), який показує графік погодинних відключень Полтаваобленерго для вашої черги: чи є світло зараз, коли наступна зміна і графік на сьогодні й завтра.

**Відкрити:** https://rmarkovdev.github.io/outage/
На iPhone відкрийте посилання в Safari, натисніть «Поділитися» → «На початковий екран».

Дані: [OE_OUTAGE_DATA](https://github.com/yaroslav2901/OE_OUTAGE_DATA), неофіційне дзеркало, яке оновлюється кожні ~5 хв. Аварійні відключення не показуються. Офіційне джерело: [poe.pl.ua](https://www.poe.pl.ua/disconnection/power-outages/).

## Розробка

```sh
python3 -m http.server 8000   # http://localhost:8000
node --test            # тести логіки
```
